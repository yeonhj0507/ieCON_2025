  • 지표 : WAPE — 낮을수록 좋음

  • 총비용 = 건설 + 생산 + 인건비 + 운송 + 재고 + 품절 + CO₂ + 모드변경 수수료
  • 최저 비용 팀 → 60 점, 최고 → 0 점 (선형)
